Como o pedido vira código

Nem todo pedido roda o ciclo inteiro. Um erro de digitação não precisa de especificação nem de plano. Estes são os seis caminhos, o que muda entre eles, e como o trabalho é verificado no fim de cada um.

Fig. 01

O ciclo, por inteiro

Você pede. O orquestrador escolhe o caminho, entrega cada etapa a um especialista e para para você conferir. O harness envolve tudo isso.

Fig. 02

Qual trilha

Duas saídas rápidas e duas perguntas, nesta ordem. Você confirma antes de qualquer etapa começar.

Fig. 03

O que cada trilha roda

As etapas são sempre as mesmas seis, na mesma ordem. A trilha só decide quais são puladas.

Fig. 04

Como uma etapa é verificada

Duas metades, nesta ordem. A primeira responde funcionou. A segunda, só depois, responde está bom.

Fig. 05

Como se prova que foi feito o que foi pedido

Cada critério tem um id. Cada teste diz qual id cobre. A matriz cruza os dois.

Fig. 06

O loop dentro de uma etapa

Implementar não é um passo só. É um ciclo curto que roda no máximo três vezes.

Fig. 07

Quando a trilha estava errada

É o que torna as trilhas curtas seguras: elas podem crescer no meio do caminho.

Fig. 08

O ciclo que melhora o ciclo

Cada sessão deixa um rastro. Ele é lido de volta para apontar onde o próprio harness está errado.

Fig. 09

O que cada trilha custa

O teto de uma trilha é a soma das etapas que ela roda. Ao estourar, a sessão para e devolve o que já fez, em vez de continuar gastando.

trilhaquandoteto
spikeuma pergunta a responder, sem mudança80k
patchtexto, versão, formatação, código morto115k
incidentprodução quebrada; mitiga antes de entender115k
fixum defeito relatado, reproduzido por um teste145k
refactora estrutura muda, o comportamento não190k
featurecomportamento que ainda não existe220k

E o teto não é a métrica. harness cost conta as sessões pelo quanto avançaram e divide o tempo de agente pelas que entregaram — porque um modelo que custa o dobro e reduz as tentativas pela metade sai mais barato, e um relatório que só soma tokens não mostra isso.
