# Dream candidates

Patterns extracted between sessions, waiting for a human to accept or reject
them. Written by the consolidation step at the start of a session, from the
material `dream-collect` gathered when the previous ones closed.

This file is not memory. `_decisions.md` is memory, and an entry gets there only
through `harness dream --promote <id>`. The separation is the point: an
extraction mistake that writes itself straight into memory is permanent, and
every later session inherits it.

Rules a candidate has to satisfy, in the order they are checked:

1. **Two sessions minimum.** One occurrence is an event. Two is a pattern.
2. **Every candidate cites its sessions.** No evidence, no candidate.
3. **A candidate that contradicts a decision points at it.** The contradiction
   is the finding, not an inconsistency to quietly resolve.
4. **Nothing the code already says.** `_context.md` holds the facts. This is
   about choices.

Discarded candidates stay, marked, so the same pattern is not proposed again
next month by an extraction that has forgotten it was already rejected.
