# Copilot adapter

The shared workspace contract is AGENTS.md. Use native skills in
.github/skills only when relevant. Path instructions merge on applyTo matches.
The structured entry point is @orchestrator or /feature; /resume continues it.
MCP is configured in .vscode/mcp.json; disabled templates are not runtime tools.
Session artifacts use specs/<id>-<slug>/ unless a Kiro installation selects
.kiro/specs/ with requirements.md and design.md. Scripts referenced as
.github/tools/ are also available through that path for a Copilot target.
