# Routing

A localized goal with a targeted check, including a new regression test, stays
in the current chat. No session, subagent or approval of a track. File count
alone does not force planning. Auth, permissions, crypto, payments, destructive
operations and production data changes require explicit scope authorization.

For multi-component changes or public contracts, the orchestrator selects
patch, fix, refactor, feature, incident or spike. One planner invocation writes
all needed requirements, design and tasks. Approve that plan once, implement,
then independently review. Do not require approvals between documents or
between implementation and review. Honor an already approved plan.

Specialists are used for an actual capability or independent judgment. A skill
is sufficient for a procedure. No delivery phase or automated Git publication.
